# News Credibility Analyzer XAI

## Description

News Credibility Analyzer XAI is a Java-based application that evaluates the credibility of news headlines using rule-based artificial intelligence techniques. The system analyzes suspicious keywords, fact-checking rules, and credibility indicators to determine whether a news headline is likely reliable or potentially misleading.

The project demonstrates Explainable AI (XAI) concepts by providing transparent explanations for every prediction, helping users understand why a headline was classified in a particular way.

## Features

* News credibility analysis
* Suspicious keyword detection
* Rule-based fact checking
* Confidence score generation
* Explainable AI (XAI) predictions
* Transparent reasoning for results

## Technologies Used

* Java
* String Processing
* Rule-Based AI
* Explainable AI (XAI)
* Conditional Logic

## How It Works

1. The user enters a news headline.
2. The system scans for suspicious keywords and misleading patterns.
3. Fact-checking rules are applied.
4. A credibility score is calculated.
5. The system provides a prediction along with an explanation.

## How to Run

Compile the program:

```bash
javac FakeNewsDetectionXAI.java
```

Run the program:

```bash
java FakeNewsDetectionXAI
```
